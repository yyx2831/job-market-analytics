## 项目亮点（供面试展开）

**按键映射引擎** — Electron + Vue3 桌面应用核心模块
> 支持多外设热插拔识别、自定义按键映射配置、实时输入反馈。技术难点：主进程硬件事件 → 渲染进程 UI 更新的低延迟通信；多设备并发时的状态管理一致性。

**实时数据可视化管道** — 硬件数据采集到前端渲染
> 从串口/HID 原始数据读取，经过数据清洗、聚合计算，到 Canvas/ECharts 实时渲染。技术难点：高频数据（50Hz+）下渲染性能优化，通过 SharedArrayBuffer + requestAnimationFrame 调度实现流畅 60fps。

**Electron 桌面端架构** — 模块化设计
> 插件化设备驱动加载、主进程服务管理、窗口生命周期控制。技术难点：主进程内存稳定性（长时间运行无泄漏），Native 模块跨平台编译兼容。
