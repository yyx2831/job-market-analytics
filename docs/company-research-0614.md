## 一、商天下科技

### 公司画像

| 维度 | 信息 |
|------|------|
| 全称 | 成都商天下科技有限公司 |
| 成立 | 2023年9月（不到3年） |
| 规模 | 100-499人（BOSS直聘标注） |
| 融资 | 未融资 |
| 办公点 | 成都武侯区紫荆 + 深圳福田中海大厦 + 杭州上城区赞成中心 |
| 业务 | 港美股证券交易软件 + IDC托管 |

### 产品推演

商天下做的不是普通网站，而是**港美股交易软件**——和富途牛牛、老虎证券、华盛通是同一赛道。

根据招聘信息推断：
- 他们有「港美股证券业务产品经理」在招 → 正在做/已经做了海外证券交易
- 深圳招金融产品经理（¥15-20K·13薪）→ 产品核心在深圳，成都和杭州是技术团队
- 同赛道竞品：富途牛牛（深圳）、老虎证券（北京）、华盛通（深圳）
- 三地办公说明可能是**白标交易软件**模式——给券商/交易商提供贴牌交易系统

**你在里面要做什么**：
- 「交易软件桌面端开发（Electron框架）」→ 和富途牛牛PC端的开放API（FutuOpenD）架构高度相似
- PC端交易界面：K线图、深度行情、下单面板、持仓管理、条件单
- 对Electron能力有硬需求：主进程负责行情数据推送（WebSocket长连接），渲染进程负责界面刷新
- 高频实时数据 = 你对口的大屏+可视化经验可以用上

**技术推演**：
- K线/行情图表 → Canvas/WebGL渲染（你做过WebGL）
- 实时数据推送 → WebSocket + 主进程分发（你做过的设备通信模式）
- 桌面端打包/发布 → Electron构建流水线（你日常在做的）
- 性能优化是重点：行情数据高频刷新时不能掉帧 → 你搞定的帧率优化直接加分

### ⚠️风险提示

1. **注册资本仅¥10万**，标注100-499人明显矛盾，可能是壳公司或信息不实
2. 成立不到3年，稳定性未知
3. 港美股交易软件涉及金融合规，牌照风险较高
4. 未融资 → 现金流靠客户，如果客户流失可能裁员

**建议**：薪资¥15-20K对你来说涨幅有限（13→15 = +15%），这种不确定性不值得跳。但如果面试下来实际能给到¥18-20K，可以当跳板——做一年交易软件经验，以后往深圳富途/老虎跳能拿到¥30K+。

## 二、相信光网络科技

### 公司画像

| 维度 | 信息 |
|------|------|
| 行业 | 互联网 |
| 规模 | 500-999人 |
| 融资 | 不需要融资 |
| 位置 | 成都武侯区中和（你家楼下） |
| 在招 | 资深前端架构师 ¥25-40K、高级测试专家 ¥22-40K·15薪 |

### 产品推演

公开信息极少，但从招聘信号可以反推：

**1. 技术团队要求不低**
- 不是招"前端开发"而是招"资深前端**架构师**"→ 有复杂前端系统需要设计
- 测试岗也开¥22-40K·15薪 → 不是外包公司，是自研产品

**2. 500-999人且"不需要融资"**
- 说明已经有稳定盈利的产品线
- 典型画像：成都本土中型互联网公司，ToC产品，DAU在百万级别
- 类比公司：成都的tap4fun、极米、Camera360这类

**3. 中和街道 + 互联网**
- 天府软件园附近，成都互联网密度最高的区域
- 大概率有移动端+PC端+管理后台全套产品

**4. 前端架构师的JD**
- "主导前端技术架构设计和优化，确保技术架构的先进性和可扩展性"
- "深入研究Web性能优化方法，全面优化网站性能"
- 这意味着他们可能正在做：微前端架构改造、性能优化专项、或新产品线从零搭建

### 你在里面要做什么

**最可能的场景**：
- 他们现有产品线在扩张，前端从几个人的小组变成需要架构师统筹
- 或者正在从单体前端迁移到微前端 + 组件库 + 工程化体系
- 或者新开一条需要复杂前端交互的产品线

**你的匹配点**：
- 你在雨林之星从零搭过Electron架构 → 这正是架构师需要的"从零设计能力"
- 你搞格式刷bug和设备通信 → 证明你能hold住复杂交互
- 你的WebGL/GIS/大屏经历 → 如果有数据可视化需求你是天然匹配

### 风险评估

- 信息不透明，无法从公开渠道查到具体产品
- 但"不需要融资"+"500-999人"+"20-40K"三者叠加 → 大概率是靠谱的中型公司
- 中和街道离家近，通勤成本极低

**建议**：这是主攻目标。¥25-40K，你争取到¥20-25K就是60-90%的涨幅。而且离家近。
